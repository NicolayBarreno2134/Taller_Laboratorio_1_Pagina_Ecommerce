# Visor Inteligente: Catálogo de Productos

¡Bienvenido! Este es un pequeño proyecto web que muestra un catálogo de productos utilizando una interfaz visual muy llamativa y futurista, diseñada para parecer un "HUD" (Heads-Up Display), similar a los visores que vemos en los videojuegos o películas de ciencia ficción.

##  ¿De qué trata?

El proyecto simula la pantalla de un visor inteligente. Al abrirlo, el sistema se conecta automáticamente a internet para consultar un catálogo de productos (ropa, joyería, electrónica, etc.) y los muestra en pantalla con sus respectivas imágenes, nombres, categorías y precios.

## Características principales

* **Diseño Futurista:** Una interfaz oscura con detalles en colores cian neón, bordes tecnológicos y tipografía de estilo terminal.
* **Datos Reales:** Los productos que se muestran no están escritos a mano, el sistema los "lee" automáticamente desde un servicio público en internet llamado *Fake Store API*.
* **Interactivo:** Cuenta con un botón de "DATA" en la parte inferior para recargar la información de los productos en cualquier momento.
* **Adaptable:** El diseño se ajusta para verse bien tanto en pantallas grandes como en dispositivos más pequeños.

## Cómo probarlo

¡Es muy fácil! No necesitas instalar ningún programa especial ni tener conocimientos de informática:

1. Asegúrate de tener los archivos `index.html` y `datosEcommerce.js` en la misma carpeta.
2. Haz doble clic sobre el archivo **`index.html`**.
3. El proyecto se abrirá automáticamente en tu navegador web favorito (Google Chrome, Firefox, Safari, etc.).
4. ¡Disfruta explorando la interfaz!

## Notas adicionales

* Requiere conexión a internet para poder descargar y mostrar las imágenes y precios de los productos.
* Este proyecto fue creado con fines prácticos para demostrar cómo conectar una página web con información externa manteniendo un diseño creativo.
